🏨 App de Gestión de Hostel
Este es un sistema local desarrollado en HTML, CSS y JavaScript para gestionar las reservas y camas de un hostel. Funciona completamente sin conexión y no requiere ningún servidor ni base de datos externa.

🚀 Características
Ver el estado (ocupado o libre) de las camas en tiempo real.

Registrar reservas con:

Nombre y nacionalidad del cliente

Fecha de entrada y salida

Cama o habitación asignada

Valor pagado

Histórico de huéspedes anteriores.

Búsqueda por nombre de cliente.

Filtro por fecha para ver reservas activas.

Edición de reservas mediante modal.

Modo oscuro (Dark Mode).

Exportación de datos a:

Archivo JSON

Archivo CSV

Importación de datos desde JSON.

Totalmente funcional en entorno local.

🛏️ Distribución de camas
Cuarto compartido: 18 camas

1s 2s 3s 4s 5s 6s 1m 2m 3m 4m 5m 6m 1i 2i 3i 4i 5i 6i

Cuarto de voluntarios: 9 camas

1s 2s 3s 1m 2m 3m 1i 2i 3i

Habitaciones privadas: 6 habitaciones numeradas de 1 a 6

Para evitar confusión entre cuartos que usan la misma numeración, cada cama está precedida por un prefijo:

C- para compartido

V- para voluntarios

P- para privados
